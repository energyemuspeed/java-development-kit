## ❓ What Is the JDK

| **Term** | **Description** |
|-----------|-----------------|
| **JVM** | Java Virtual Machine — runs bytecode |
| **JRE** | Java Runtime Environment — runs apps |
| **JDK** | Java Development Kit — builds apps |
| **javac** | Java compiler |
| **jar** | Java archive tool |
| **jshell** | Interactive Java REPL |

**Why use the JDK?**
- ✅ Compile and run Java code
- ✅ Build backend services
- ✅ Package deployable apps
- ✅ Cross-platform by default
- ✅ Free and open source

## 🔧 Setup Walkthrough

### Step 1 — Choose Your JDK
Pick Java 17 or 21 LTS for long-term support.

### Step 2 — Install
Use MSI on Windows, pkg or Homebrew on macOS, apt/dnf on Linux.

### Step 3 — Set Environment
Configure `JAVA_HOME` and update `PATH`.

### Step 4 — Verify
Run `java -version` and `javac -version`.

### Step 5 — Compile and Run
Create `Hello.java`, compile with `javac`, run with `java`.

### Step 6 — Package
Build a JAR with Maven or Gradle, then wrap with jpackage.

## 🌐 How To Use

### First Steps

1. **Read** the JDK overview
2. **Install** the JDK
3. **Set** environment variables
4. **Compile** your first class
5. **Build** with Maven or Gradle
6. **Package** a runnable app

### User Tips

- ✅ Keep multiple JDKs side by side
- ✅ Switch versions with SDKMAN or jenv
- ✅ Use `--release` flag for target compatibility
- ✅ Prefer jlink for small runtimes
- ✅ Use jpackage for native installers

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **javac not found** | Add JDK to PATH |
| **Wrong Java version** | Check `JAVA_HOME` |
| **Build fails** | Update Maven / Gradle |
| **Module error** | Verify `module-info.java` |
| **jpackage fails** | Install WiX (Windows) |
| **Slow build** | Enable daemon in Gradle |
